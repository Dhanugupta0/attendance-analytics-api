## Looked at and decided not a defect

1. **`load_dotenv()` without `override=True`**: This is standard behavior because real system environment variables should take precedence over local `.env` settings.
2. **Fixed IST offset (+05:30)**: Indian Standard Time has no daylight saving time, so a fixed offset `timezone(timedelta(hours=5, minutes=30))` is exact and reliable.
3. **Synchronous PyMongo with plain `def` endpoints**: FastAPI automatically runs synchronous endpoints in a thread pool, allowing concurrent requests to run without blocking.
4. **Pydantic `model_dump()`**: In Pydantic v2, `model_dump()` is the standard supported method for converting validated models into Python dictionaries.
