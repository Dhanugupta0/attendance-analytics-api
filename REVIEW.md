## Looked at, not a defect

1. **`load_dotenv()` without `override=True`**:
   The default behavior loads variables from `.env` only if they are not already set in the system environment. This is standard and desired behavior so production container environments and CLI overrides take precedence over local configuration files.
2. **Fixed IST offset (+05:30)**:
   The Indian Standard Time offset is defined as UTC+5:30 without Daylight Saving Time. Using a fixed `timezone(timedelta(hours=5, minutes=30))` is robust, standard, and avoids external zoneinfo dependency issues.
3. **Synchronous PyMongo with plain `def` endpoints**:
   FastAPI automatically runs standard synchronous `def` endpoints in a thread pool (`anyio.to_thread.run_sync`), allowing concurrent requests to execute in parallel without blocking the async event loop.
4. **Pydantic `model_dump()`**:
   Using `model_dump()` in Pydantic v2 is the recommended standard method for extracting dictionary representations from validated models.
